# IS4542 Mock Equity Feed

Public teaching demo for [CityU](https://www.cityu.edu.hk/) IS4542 (AI Agents, Semester B 2026/27).

**Live site:** https://abc1235647899.github.io/is4542-mock-equity-feed/

This is synthetic educational data only (`is_mock=true`). Quotes are 15-minute delayed teaching figures, not real-time HKEx OMDC. The text is original mock copy, not scraped from Quamnet, Infocast, AA Stocks, Bloomberg, or HKEx. This is not a Quam, Quamnet, or Hong Kong Exchanges product, and it is not investment advice.

Open the live site to browse watchlists, quote cards, news, IIS-style announcements, company profiles, and a simple keyword search with citations.

Use **Generate new feed** to walk prices and news forward by one mock trading session in your browser. That copy stays on your device only; refreshing the page keeps it. **Restore published snapshot** returns to the shared teaching set (as-of 13 Nov 2026, seed 4542).


Columnist articles, AA Stocks-style news, and social-media sentiment posts are included only as later-phase samples. They are clearly labelled and are not in the Semester B passing scope.
